## 🚀 **How to Deploy**

### **Option 1: Automated (Recommended)**
1. Push your code to GitHub
2. Enable GitHub Pages in repository settings
3. Set source to "GitHub Actions"
4. Your app will be automatically deployed!

### **Option 2: Manual**
```bash
./deploy.sh
```
